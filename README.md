# HR Analytics Dashboard

Portfolio project for workforce reporting using Python, SQL and Power BI.

## Business objective
Create an executive view of workforce size, attrition, salary, performance and hiring patterns to support workforce planning.

## Dataset
18,000 employee records containing department, age, salary, performance rating, tenure, overtime, training hours, hire year and attrition.

## Workflow
- Validate data quality and duplicates
- Calculate department-level workforce KPIs
- Analyse attrition by department and overtime
- Analyse hiring trends over time
- Prepare dashboard-ready insights

## Dashboard
Preview visuals are stored in images/. The dashboard guide in dashboard/ documents the KPI cards, charts, filters and layout.

## Repository structure
- data/ — source dataset
- notebooks/ — reproducible analysis
- sql/ — business queries
- dashboard/ — Power BI build notes
- images/ — dashboard previews
- requirements.txt — dependencies

## Run
Install requirements.txt and open notebooks/hr_analytics_dashboard.ipynb in Jupyter.

## Skills demonstrated
Python, Pandas, EDA, SQL, Power BI, KPI reporting and business interpretation.
